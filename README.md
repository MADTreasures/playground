## Fluency – Live-Übersetzer für Android, vollständig offline

- **App installieren**: [`dist/Fluency-1.1.0.apk`](dist/Fluency-1.1.0.apk). Neu in 1.1.0: Die
  Übersetzung läuft auf der Adreno-GPU, wenn sie auf dem Handy mindestens ähnlich schnell ist wie
  die CPU (automatisch gemessen).
- **Projekt für Android Studio**: [`dist/Fluency-AndroidStudio-1.1.0.zip`](dist/Fluency-AndroidStudio-1.1.0.zip)
  (entpacken → in Android Studio öffnen → Run). Alternativ funktioniert auch „Code → Download ZIP“
  dieses Repos; dann den Ordner `fluency` öffnen.
- Beschreibung, Modelle, Build und Tests: [`fluency/README.md`](fluency/README.md)
